# Schriftarten-Lizenzen

[RetroRadio](../../README.md) > [Dokumentation](../../README.md#dokumentation) > [Lizenzen](../LIZENZEN.md) > Schriftarten-Lizenzen

Die GUI bettet Schriftarten als konvertierte Font-Header ein (`include/fonts/`). Dieses Verzeichnis enthält die zugehörigen Lizenztexte gemäß den Beilage-Pflichten der jeweiligen Lizenz.

| Font-Header | Schriftart | Urheber | Lizenz | Lizenztext |
|---|---|---|---|---|
| `ComfortaaBold10/14/16/18/30.h` | Comfortaa Bold | The Comfortaa Project Authors (Johan Aakerlund) | SIL OFL 1.1, Reserved Font Name "Comfortaa" | [OFL-Comfortaa.txt](OFL-Comfortaa.txt) |
| `AtkinsonHyperlegibleNextMedium11.h` | Atkinson Hyperlegible Next Medium | The Atkinson Hyperlegible Next Project Authors (Braille Institute) | SIL OFL 1.1 | [OFL-AtkinsonHyperlegibleNext.txt](OFL-AtkinsonHyperlegibleNext.txt) |
| `LeagueGothicCond34.h` | League Gothic, Breite 77 der Achsenschrift | The League Gothic Project Authors (Tyler Finck, Caroline Hadilaksono, Micah Rich) | SIL OFL 1.1 | [OFL-LeagueGothic.txt](OFL-LeagueGothic.txt) |

Die Schriftdateien sind in konvertierter Form in der Firmware enthalten. Die Urhebervermerke und vollständigen Lizenztexte liegen in diesem Verzeichnis. Die Weboberfläche bettet ihre Schrift lokal ein und enthält den zugehörigen Lizenztext im HTML-Quelltext.
